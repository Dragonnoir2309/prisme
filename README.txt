PRISME — VERSION HORS CONNEXION

1. Héberge ce dossier une première fois sur une adresse HTTPS.
2. Ouvre l’adresse dans Safari sur l’iPhone.
3. Choisis Partager → Sur l’écran d’accueil.
4. Lance Prisme depuis l’icône.
5. Après la première mise en cache, le jeu peut fonctionner sans connexion.
